Project story — Custom pools

The pool is the garden's centre, not an afterthought.

Rolling Stone's custom pools are designed with the landscape around them — levels, planting, stone and light all resolved before a single trench is dug. The result reads as one calm outdoor room, not a pool dropped into a yard.

Every project is quoted individually. There are no package prices here, because no two sites — slope, soil, aspect, existing trees — are ever the same.

Project story — Planting & structure

Planting that looks like it was always there.

The studio's "Quiet Luxury" projects favour restraint: generous lawns, layered planting, stone and timber chosen to age well. Nothing shouts. Everything is placed — a garden you live in daily, not one you photograph once.

Design and construction come from the same team, so what is drawn is what is built — and what is built is maintained to the same standard.
